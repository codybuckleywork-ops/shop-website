# Shop website

Static site, hosted free with GitHub Pages.

- `/` — the sign shop's customer-facing site
- `/project/` — landing page for the Signshop Dashboard software

To publish: repo Settings → Pages → Source: "Deploy from a branch" →
Branch: main, folder: / (root) → Save. Live in ~1 minute at
https://codybuckleywork-ops.github.io/shop-website/
